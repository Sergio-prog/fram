## Theme: agent-friendliness

The user's stated direction is "CLI and agent usage." Several plans add affordances that
make Fram scriptable by another program/agent (stable exit codes already exist via
`typer.Exit(1)`; `do`/recipes give a single-invocation pipeline; `--json`/quiet output is
called out as a follow-up in 002's maintenance notes). A dedicated "machine-readable output
mode" plan was **considered and deferred** (see below) — it is worth doing but was not part
of this batch.
